## 2. Deployment package contract

The **deployment package** is a directory tree containing **only public artifacts** copied from the Static Provider source root.

| Path pattern | Included in package |
|--------------|---------------------|
| `{slug}/index.html` | **YES** (single path-segment slug) |
| `sitemap.xml` | **YES** |
| `rss.xml` | **YES** |
| `{slug}/metadata.json` | **NO** — operator; **excluded** |
| `{slug}/source.md` | **NO** — operator; **excluded** |
| Root `index.html` | **NO** (not generated by Static v1.0) |
| CSS / JS / images | **NO** (not generated by Static v1.0) |

**Rule function (frozen):** `contract.is_public_artifact(relative_path)`.

**Operator exclusion (verified M5.5):** `metadata.json` and `source.md` remain in `output/website/` but are **never** copied into `packages/{deployment_id}/`.

---

## 3. Public subset rules (frozen)

```text
PUBLIC  :=  {slug}/index.html  where slug is one segment, not empty, not dot-prefixed
         |  sitemap.xml
         |  rss.xml

EXCLUDED := all other files under source root (including metadata.json, source.md)
```

Constants: `PUBLIC_PAGE_ARTIFACT_NAME`, `PUBLIC_ROOT_FEED_NAMES`, `OPERATOR_ARTIFACT_NAMES` in `contract.py`.

## 5. Deployment manifest format (frozen)

**Filename:** `deployment-manifest.json` (`MANIFEST_FILENAME`)  
**Location:** inside each `packages/{deployment_id}/` directory  

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `schema_version` | string | yes | `"1.0"` |
| `deployment_id` | string | yes | `dep_{12 hex}` |
| `created_at` | string | yes | UTC ISO-8601 |
| `source_root` | string | yes | Absolute path to Static output |
| `package_root` | string | yes | Absolute path to this package |
| `files` | array | yes | Per-file entries (see below) |
| `public_file_count` | int | yes | Count of copied public files |
| `provider_target` | string | yes | e.g. `cloudflare_pages`, `local_static` |
| `rollback` | object | yes | `previous_deployment_id`, optional hints |
| `cloudflare` | object | optional | Pages metadata (no secrets) |
| `local` | object | optional | Reserved |

**File entry:**

| Field | Description |
|-------|-------------|
| `path` | POSIX relative path within package |
| `sha256` | Lowercase hex SHA-256 of file bytes |
| `bytes` | File size |

Manifest file itself is **not** listed in `files[]`.

---

## 6. SHA-256 verification (frozen)

- Algorithm: SHA-256 over raw file bytes (`manifest.sha256_file`).  
- Verification: re-hash each `files[].path` under package root; must equal `files[].sha256`.  
- Used for release/rollback attestation (see Ledger evidence).

---

## 7. Snapshot format (frozen)

- **Path:** `output/website-deploy/snapshots/{deployment_id}/`  
- **Content:** Recursive copy of `packages/{deployment_id}/` at export completion (includes manifest).  
- **Purpose:** Local rollback source when re-deploying a prior `deployment_id` via `deploy_local(..., export_first=False)`.

---

## 8. Rollback history (frozen)

- **Path:** `output/website-deploy/rollback-history.jsonl`  
- **Format:** One JSON object per line (append-only).  
- **Typical fields:** `deployment_id`, `provider_target`, `package_root`, `snapshot_root`, `manifest_path`, `previous_deployment_id`, `public_file_count`, optional `event` (`local_deploy`), `recorded_at`.

---

## 9. Cloudflare template contract (frozen)

Generated under `deploy_root/cloudflare/` — **not** uploaded by Core/Adapter automatically.

| File | Role |
|------|------|
| `wrangler.toml` | Project name + compatibility_date; operator runs Direct Upload |
| `_headers` | Deny hints for operator paths if mis-copied |
| `_redirects` | Placeholder (no default redirects) |
| `README-CLOUDFLARE-PAGES.md` | Operator instructions |

**Default project name:** `founder-website` (`DEFAULT_PAGES_PROJECT`).  
**No Cloudflare SDK/API calls** in adapter code.

---

## 10. Local Nginx/Caddy contract (frozen)

- **Method:** `DeploymentAdapter.deploy_local(target_dir, deployment_id=..., export_first=...)`.  
- **Behavior:** Replace `target_dir` with contents of `packages/{deployment_id}/`.  
- **Docroot:** Operator points Nginx/Caddy `root` at `target_dir`.  
- **TLS:** Operator-managed (Caddy auto-HTTPS or Nginx + ACME).  
- **Portable fallback:** Same public package tree used for Cloudflare Direct Upload.
