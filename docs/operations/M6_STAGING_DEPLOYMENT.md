## Operator unblock (staging only)

1. Create Cloudflare API token (Pages edit) in dashboard — store in Shared Platform secrets.  
2. Export token to env **locally or in CI** (name only in docs): `CLOUDFLARE_API_TOKEN`, optionally `CLOUDFLARE_ACCOUNT_ID`.  
3. Create Pages project `founder-os-staging-m6` (or use existing **non-production** project).  
4. Deploy from `output/website-deploy/packages/dep_m6_staging/` — **do not** attach production custom domain.  
5. **Security note:** Before edge upload, omit `deployment-manifest.json` from the uploaded tree (contains local `source_root` path) or upload only HTML + XML files. See [M6_STAGING_SECURITY_AUDIT.md](M6_STAGING_SECURITY_AUDIT.md).  
6. Record `*.pages.dev` preview URL in this doc on success.
