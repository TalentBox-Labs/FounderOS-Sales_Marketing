# UI-D1 Navigation Contract

## Primary (Founder)

- Command Center → `/command`
- Demand & Contacts → `/demand`
- Approvals → `/pending-approvals`
- Activity → `/activity`
- Revenue Workflow → `/operator`

## Secondary (Content Ops)

Collapsed under `<details>` in sidebar: Dashboard, legacy Cockpit, Analytics, Content Studio, Editorial, Publishing, SEO, Pipeline, Marketing, Sales, MCP.

## Shell

- Organization name shown when tenant context resolves (`tenant.organization_name`)
- Mobile: sidebar toggle via ☰ button
- Sign out when human session present
