# Founder OS ACP-2 — Work Lifecycle

States: `PROPOSED → ELIGIBLE|BLOCKED|WAITING_HUMAN|CANCELLED`
`ELIGIBLE|RETRYABLE → RUNNING → SUCCEEDED|FAILED|RETRYABLE|WAITING_HUMAN|BLOCKED`
`RETRYABLE → RUNNING|EXHAUSTED`

Forbidden: `BLOCKED|EXHAUSTED|CANCELLED|WAITING_HUMAN|SUCCEEDED → RUNNING` (no silent resurrection).

Implemented in `acp2_work_contract.py` + `acp2_orchestration.py`.
